# Hermes 작업 대시보드

Hermes의 작업 큐, 실행기 상태, 토큰 사용량과 활동을 한 화면에서 관리하는 반응형 한국어 정적 대시보드 목업입니다.

## 실행

별도 설치나 빌드가 필요하지 않습니다. `index.html`을 브라우저에서 직접 열거나 정적 서버로 실행하세요.

```sh
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다.

## 기능

- 15rem 사이드바와 3rem 헤더 기반 반응형 앱 셸
- KPI 5종, 작업 큐 검색·필터·다중 선택
- 에이전트 상태, 최근 활동, 7일 작업량 SVG 차트
- 액션 토스트, 테마 전환, 모바일 내비게이션
- 키보드 포커스 스타일과 접근 가능한 레이블/표 구조

모든 리소스는 저장소 안에 있으며 외부 CDN, 프레임워크, 네트워크 에셋을 사용하지 않습니다.
